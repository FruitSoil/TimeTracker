# TimeTracker
A very simple program, built for personal use. It features basic timer functionality—setting the time, pausing, stopping—and a history log.
The code is an absolute disaster. JSON data is stored as strings rather than numbers, and the timer sound is just a random TikTok video (I’m not even joking).
You can change the sound in the settings. You can also shrink the window size if you don’t want the tracker taking up your entire screen.
